## 🖥️ Установка на Windows

1. Скачайте последнюю версию и распакуйте
2. Установите [**`Python 3.12`**](https://www.python.org/downloads/release/python-31210/) ⚠️ **Важно: именно эта версия!** 
3. Запустите `Setup.bat` для установки зависимостей
4. Запустите `start.bat`
5. Следуйте инструкциям для настройки бота

💡 После ввода токена бот сам проверит, открывается ли Telegram напрямую. Если нет (например, в России) — предложит бесплатный Cloudflare Worker или прокси. Подробнее: [Подключение к Telegram](#-подключение-к-telegram).

## 📡 Подключение к Telegram

Бот умеет подключаться к Telegram тремя способами:

| Способ | Цена | Когда подходит |
|---|---|---|
| 🌍 **Напрямую** | бесплатно | Telegram у сервера открывается без ограничений (например, сервер в Нидерландах) |
| ☁️ **Cloudflare Worker** | бесплатно | Telegram заблокирован, а Cloudflare доступен. Нужна только почта |
| 🌐 **Прокси** | платно | Есть свой прокси не RU региона ([купить](https://proxylin.net?ref=448587)) |

**Способ можно выбрать при установке или в настройках.**


**В Telegram-боте:** ⚙️ Настройки → 📡 Подключение к Telegram. Там можно выбрать основной способ (бот сначала проверит его и переключится только если он работает), добавить, изменить и удалить воркер или прокси, проверить все способы разом и включить/выключить автопереключение.

**Автопереключение.** Если основной способ перестал отвечать, бот сам переходит на запасной в порядке **прокси → воркер → напрямую** (только среди настроенных), пишет об этом в Telegram и каждые 10 минут проверяет основной способ, чтобы вернуться на него.

### ☁️ Как создать Cloudflare Worker (≈5 минут)

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) (почта + пароль, карта не нужна).
2. В меню слева: **Workers & Pages** → **Create** → **Create Worker** (может называться «Start with Hello World»).
3. Придумайте имя, например `tg-proxy`, нажмите **Deploy**.
4. Нажмите **Edit code**, полностью удалите шаблонный код и вставьте:

```js
export default {
  async fetch(request) {
    const url = new URL(request.url);
    const tgUrl = `https://api.telegram.org${url.pathname}${url.search}`;
    const headers = new Headers(request.headers);
    headers.set('Host', 'api.telegram.org');
    return fetch(new Request(tgUrl, {
      method: request.method, headers, body: request.body
    }));
  }
}
```

5. Снова нажмите **Deploy**.
6. Скопируйте адрес воркера вида `https://tg-proxy.ваш-поддомен.workers.dev` и вставьте его в бот (в установщике или в меню 📡).


### ⚙️ Настройки в `bot_settings/config.json`

Раздел `telegram.api` (не `config.py`):

| Поле | Значение |
|---|---|
| `mode` | основной способ: `direct`, `worker` или `proxy` (пусто — автоматически) |
| `custom_api_url` | адрес воркера, например `https://tg-proxy.name.workers.dev` |
| `proxy` | прокси только для Telegram: `ip:port`, `user:pass@ip:port`, `socks5://user:pass@ip:port` |
| `auto_fallback` | `true` — переключаться на запасной способ при сбое |

> Прокси для **Playerok** настраивается отдельно (⚙️ Настройки → 📶 Соединение) и на подключение к Telegram не влияет. Cloudflare Worker используется только для Telegram.
